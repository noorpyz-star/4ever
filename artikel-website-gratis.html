🌐 Cara Membuat Website Gratis Sendiri di GitHub Pages

4EVER.AI.ID

Ditulis oleh Afis • 15 November 2026

Punya website sendiri tidak harus bayar hosting. Website yang sedang kamu baca ini — 4ever.ai.id — dibuat dan di-hosting gratis pakai GitHub Pages. Tidak ada biaya bulanan, tidak ada iklan dari hosting, dan kamu yang pegang penuh kendali atas isinya.

Berikut langkah-langkahnya, dari nol sampai website kamu online.

1. Buat Akun GitHub

Buka github.com dan daftar akun gratis. Pilih username yang gampang diingat, karena nama ini akan muncul di alamat website kamu nanti.

2. Buat Repository Baru

Setelah login, klik tombol New repository. Isi nama repository — misalnya website-saya — lalu buat repository-nya. Repository ini tempat semua file website kamu disimpan.

3. Upload File HTML Kamu

Di dalam repository, klik Add file lalu Upload files. Upload file HTML kamu — file utamanya harus bernama index.html, karena itulah halaman yang dibuka pertama kali saat orang mengunjungi website kamu. Kalau belum punya file HTML, kamu bisa mulai dari satu file index.html sederhana berisi teks "Halo, ini website saya".

4. Aktifkan GitHub Pages

Masuk ke Settings repository, pilih menu Pages. Di bagian Branch, pilih main lalu tekan Save. Tunggu 1–2 menit, lalu refresh — GitHub akan menampilkan alamat website kamu, biasanya https://username.github.io/website-saya/. Website kamu sudah online.

5. Pasang Domain Sendiri (Opsional)

Kalau mau alamat yang lebih gampang diingat, kamu bisa membeli domain sendiri (misalnya di Niagahoster atau Cloudflare) lalu mengarahkannya ke GitHub Pages. Caranya: buat file bernama CNAME di repository berisi nama domain kamu, lalu atur DNS domain ke alamat GitHub Pages. Langkah ini tidak wajib — website kamu tetap jalan dengan alamat github.io.

6. Update Website Kamu

Mau ubah isi website? Upload ulang file yang sudah diubah ke repository yang sama. Perubahan biasanya tampil dalam 1–2 menit. Semudah itu.

Apa Saja yang Bisa Dibuat?

  • Portofolio — pamer karya, CV, dan kontak kamu.
  • Link hub — satu halaman berisi semua link sosial media kamu, seperti website ini.
  • Landing page — halaman promosi produk atau jasa.
  • Blog sederhana — tulis artikel dalam file HTML, satu artikel satu halaman.

Yang tidak bisa: website yang butuh server dan database, seperti toko online dengan keranjang belanja atau sistem login. GitHub Pages hanya melayani file statis (HTML, CSS, JavaScript) — tapi untuk kebanyakan kebutuhan personal, itu sudah lebih dari cukup.

💡 Intinya: akun GitHub gratis + satu file index.html + aktifkan Pages = website kamu online dalam 10 menit. Tidak perlu kartu kredit, tidak perlu sewa server.
