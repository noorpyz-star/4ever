Main Online Berdua (Jarak Jauh 💙)

Di tiap game pilih Online: satu buat room, satu gabung pakai kode 4 huruf — langsung main dari HP masing-masing, tanpa gantian HP dan tanpa deploy apa-apa. Bisa juga 1 HP gantian kalau lagi bareng.

Cara pasang di situsmu: upload file-file ini ke repo GitHub (satu folder): game-hub-afis-dita.html, game-tictactoe.html, game-kuis-pasangan.html, game-tebak-kata.html, game-ular-tangga.html, foto-afis-dita.jpg, foto-afis.jpg, foto-dita.jpg.

Mode online: langsung jalan, tanpa deploy apa-apa — koneksi HP-ke-HP lewat server gratis PeerJS. Catatan: Ular Tangga masih pakai cara lama (butuh deploy Worker ular-game dari file yang sudah dibuat sebelumnya); kalau mau, nanti aku ubah juga ke mode online yang sama. File game-couple-worker.js tetap ada sebagai cadangan kalau suatu saat mau pindah ke server sendiri.
