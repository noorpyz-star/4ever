Main Online Berdua (Jarak Jauh 💙)

Di tiap game berdua pilih Online: satu buat room, satu gabung pakai kode 4 huruf — langsung main dari HP masing-masing, tanpa gantian HP dan tanpa deploy apa-apa. Bisa juga 1 HP gantian kalau lagi bareng.

Tidak ada game di kategori ini.
17 game gratis, tanpa download: 7 game berdua, 6 arcade, 4 puzzle. Semua jalan langsung di HP & laptop — tanpa aplikasi, tanpa daftar.

Mode online: langsung jalan, tanpa deploy apa-apa — koneksi HP-ke-HP lewat server gratis PeerJS. Game berdua (Ular Tangga, Tic Tac Toe, Kuis Pasangan, Tebak Kata, Balapan Motor) sudah pakai mode online yang sama (PeerJS, tanpa deploy). File game-couple-worker.js tetap ada sebagai cadangan kalau suatu saat mau pindah ke server sendiri.
